概览

本工具是自托管的 Telegram 多账号管理器：会话加密存本地 SQLite，可通过网页或机器人操作。适合批量导入、健康检查、清设备、群发、线索采集、号包 ZIP 工具等。

右上角「访问令牌」：若配置了 TAM_WEB_TOKEN 在此填入；本机免令牌模式可留空。顶栏还有一键体检、热重载、错误日志。

快速开始

  • 双击 start.bat（Windows）或运行 ./start.sh，选择本机/服务器、网页/机器人/两者。
  • Windows「无法验证发布者」属未签名脚本提示，点运行即可；或先运行 unblock.bat / 属性里「解除锁定」。
  • 浏览器打开提示地址（本机默认 http://127.0.0.1:8848）。
  • 先点「一键体检」，再导入账号。

账号管理

  • 添加账号：别名、手机号、代理、标签、取码链接等。
  • 勾选 + 批量栏：健康检查、自动登录、发消息、养号、代理体检、OKPay 余额、踢设备、打标签、导出、重生会话、删除等。
  • 点开一行：资料、健康检查、限制检测、设备/会话、登录、清设备、导出、重生、二验状态/重置、退出、删除。
  • 状态：active 正常、restricted 受限、banned 封禁、unauthorized 未登录/失效等。
  • 批量操作有真实进度（完成数/成功/失败/当前号）；并行与超时见参数面板。

导入

入口说明
批量导入每行 手机号|取码链接，可试运行。
session 导入上传 .session / zip，或服务端路径，或 StringSession 文本。
tdata 导入上传含 tdata 的 zip 或填路径；内置解析，无需 opentele。
导入使用 NDJSON 流式进度，弹窗会显示当前序号/总数，不再是卡住的假进度条。同一 user_id 会合并到已有记录。

导出

  • StringSession / .session / 号包 zip（session+json）。
  • tdata：真 Desktop 目录结构（需服务器安装 opentele）。缺失时弹窗可一键安装。

导出只转换库内已有会话，不会新开授权。凭证等同登录权，勿外泄。

重生会话（网页防找回）

与机器人「防找回」同类：新设备指纹重新登录，旧 session 尝试注销，库内换成新会话并重置接管时间。

  • 需要手机号；有 2FA 须填密码（已保存在本工具的二验会自动使用；批量可统一密码）。
  • 成功后再导出；tdata 不会在重生时自动生成。
  • 限流：短时间多次重生或多次错 2FA，Telegram 会返回 PhonePasswordFlood（登录次数过多）。需等待数小时～24 小时，期间不要反复点重生。

扫码登录

账号详情里点「扫码登录」：网页显示二维码，用手机已登录的官方 Telegram 扫描授权，会话加密入库。无需短信验证码；若开启云密码，扫码后需再填一次。

  • 适合无取码链接、或想快速接管已在手机上的号。
  • 二维码约 30 秒过期，页面会提示刷新；不要多开重复发起以免限流。

自动登录

依赖账号上的取码链接。无链接时请手动登录、扫码登录，或直接导入 session/tdata。

清设备 / OKPay

  • 自动清设备：按「本机接管时间」起算；详情可设是否参与、周期、循环。
  • 踢其它设备会校验是否踢干净，失败按重试间隔再试。
  • OKPay 余额：对已登录号查询（需对应业务配置）。

任务与线索

群发、采集最近发言人等走任务中心；可看进度、停止。线索库可筛选后再用于群发。

二验与重置

  • 改二步验证：工具箱 / 详情，可选把新密码加密存库。
  • 二验状态：是否开启 2FA、是否绑定辅助邮箱、是否处于重置等待期。
  • 发起 2FA 重置：走官方流程，通常约 7 天等待；到期后云密码失效。有辅助邮箱时原持有人仍可能用邮箱恢复——重置前请先查状态。
  • 取消 2FA 重置：取消进行中的等待。
  • 支持单号与多选批量。

工具箱

对库内已选账号批量执行：筛活、限制检测、隐私、筛料、改二验、二验状态/重置、清通讯录/会话、防找回清理、屏蔽/取消屏蔽用户、搜索公开群、加群、成员列表、读群消息、踢设备等。危险项会确认。

ZIP 工具（不碰库内号）

  • 拆包 / 合并 / 注册时间分类 / 转 API：与机器人号包能力对齐。
  • 格式互转：Session→Tdata（需 opentele）或 Tdata→Session（内置解析）。
  • Passkey：上传 session 号包，初始化 Passkey 注册并下载凭证 zip（创建方向）。

结果请下载后点「用完删除」。号包类移植自 GAFBot（MIT），见 NOTICE.GAFBot。

热重载与错误日志

  • 热重载：真实重启后端进程（os.execv），不是刷新页面。进行中任务会中断；约 1–3 秒后前端自动探测恢复。
  • 错误日志：记录服务端未捕获异常、HTTP 5xx、前端脚本错误。可列表查看、导出 JSON 上报、清空。
  • 文件副本：数据目录下 errors.log（DB 异常时仍可留痕）。

参数与布局

  • TAM_BATCH_CONCURRENCY：批量并行（1–32）。
  • TAM_REGEN_CONCURRENCY：重生并行（1–8）。
  • TAM_UI_OP_TIMEOUT：单号超时秒数，超时跳过避免卡死。

网页与机器人

TAM_FRONTEND=both 时同一进程开网页+机器人，共享 .env 与数据目录，但账号库只由网页/API 使用。机器人默认处理临时号包 ZIP，不自动写入托管表。Passkey/格式互转等号包能力两边均有入口；踢设备、登录、任务中心以网页为准。

AI 助手

右下角 ✦ 或顶栏「AI 助手」打开侧栏。配置上游（OpenAI 兼容 / Claude / Gemini / Azure）与 Key 后，勾选启用 AI 助手并点「保存配置」才会生效；关闭启用开关后同样要点保存，否则不生效。权限可用预设（只读/安全/标准/完整）点「套用预设到勾选」，或逐项勾选工具。升级后新增工具会按当前预设自动补默认开关。标准预设不含注销账号/退出登录；完整预设才包含。登录与导入导出 session 永不对 AI 开放。

安全注意

  • 主密钥加密会话；备份 .env / 主密钥，丢失无法解密旧会话。
  • 导出、重生、转 API 产物等同登录凭证，勿公开传播。
  • 服务器请用强令牌并建议 HTTPS；默认本机 127.0.0.1。
  • 只读/Agent 令牌不能做导入登录等写操作；热重载在只读模式下禁用。
