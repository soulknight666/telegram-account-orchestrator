# Security Policy

## Sensitive material

Never submit Telegram API credentials, bot tokens, web tokens, session strings, `.session` files, `tdata`, two-factor passwords, databases, proxy credentials, payment credentials, or account ZIP archives.

Run `python tools/audit_public_release.py --tracked-only` before publishing changes.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories for `soulknight666/telegram-account-orchestrator`. Include affected versions, reproduction steps, impact, and a minimal fix suggestion when available.

## Supported version

Security fixes target the latest tagged release and the `main` branch.
