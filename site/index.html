Telegram Account Orchestrator

TAO 将 Telegram 多账号、会话、tdata 导入、健康检查和自动化能力集中到一个可自托管工具中。Windows 提供图形界面，Linux 支持 Docker Compose 与 systemd 无桌面部署。

下载 Release 查看 GitHub 仓库
Windows GUI可视化配置、检查、启动、停止与日志查看。
Headless Linux终端配置、Docker Compose、systemd 与 SSH 隧道。
多入口自动化Web、CLI、Bot、REST API、MCP 与 Telethon。
